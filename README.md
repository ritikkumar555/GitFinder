# 🔎 GitFinder

GitFinder is a responsive GitHub profile search application that allows users to search for GitHub developers and explore their profiles, repositories, and recent activity through the GitHub API.

The project focuses on creating a clean, responsive UI while working with APIs, asynchronous JavaScript, DOM manipulation, and dynamic rendering.

## ✨ Features

* 🔍 Search for GitHub users by username
* 👤 Display GitHub profile information
* 📦 View popular/public repositories
* ⚡ Display recent GitHub activity
* 🔗 Direct links to GitHub profiles and repositories
* 📱 Responsive design for different screen sizes
* 🎨 Interactive UI elements and hover effects
* 💡 Search input focus and interactive states
* ⚠️ Handles invalid or unavailable GitHub usernames

## ⚙️ How It Works

1. Enter a GitHub username in the search field.
2. GitFinder sends a request to the GitHub API.
3. The application processes the returned JSON data.
4. The user's profile information is dynamically rendered.
5. Repository and activity information is displayed on the profile page.
6. Users can navigate directly to the GitHub profile or repositories.

## 🔌 API

GitFinder uses the **GitHub REST API** to retrieve publicly available GitHub data.

The application fetches information such as:

* User profile
* Followers and following
* Public repositories
* Repository details
* Recent public activity
